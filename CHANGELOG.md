## [1.0.0] - 2026-07-24

### Added

- Clean Architecture modular-monolith banking domain and application services.
- Customer and account lifecycle REST APIs.
- Deposits, withdrawals, atomic transfers, and immutable ledger history.
- PostgreSQL JDBC persistence, Flyway migrations, optimistic locking, and
  idempotent money operations.
- OAuth 2.0 JWT scope authorization and secured local Keycloak deployment.
- OpenAPI 3.1 contract with Swagger UI and automated conformance checks.
- Health probes, Prometheus metrics, audit events, and correlation IDs.
- Testcontainers PostgreSQL integration and secured end-to-end testing.
- Architecture, formatting, coverage, static-analysis, dependency, secret,
  configuration, and container security gates.
- Docker packaging, Compose deployment, GitHub Actions, and open-source
  community documentation.
