# Support

This project is maintained on a best-effort community basis.

- Use GitHub Discussions, when enabled, for usage and design questions.
- Use GitHub Issues for reproducible defects and focused feature proposals.
- Use private security advisories for vulnerabilities or sensitive reports.

Include the application version, Java version, operating system, active Spring
profiles, sanitized logs, and minimal reproduction steps. Never post tokens,
passwords, database dumps, customer information, or unredacted production
configuration.

There is no guaranteed response time, service-level agreement, or warranty.
Commercial or operational support is not provided by the Apache 2.0 license.
